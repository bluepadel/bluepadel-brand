BluePadel logos - print-clean vector artwork (25 Nov 2026)

Solid vector shapes only: no images, no transparency, no clipping masks, no borders.
Each colour is ONE welded shape (one-colour files: a single shape; the white highlights are
true holes, so the fabric shows through).

CorelDRAW tip: Corel adds a white page rectangle when it imports a PDF or EPS. Either
import the SVG (no rectangle), or select the logo, Ungroup All (Ctrl+U), click the white
rectangle and press Delete.

Note: the 'for-dark-fabric' and 'one-colour_white' files are WHITE artwork for dark shirts,
so they look blank on a white page.
Formats: SVG, PDF and EPS. All three hold the same artwork; use whichever your software opens best
(CorelDRAW: EPS or PDF; Illustrator: PDF, EPS or SVG).

Files
- BluePadel_logo_horizontal_*   figure + "BluePadel" + slogan, side by side
- BluePadel_logo_stacked_*      figure above the wordmark
- BluePadel_mark_*              the player figure on its own
- full-colour_for-light-fabric  for white garments
- full-colour_for-dark-fabric   for brand-blue / navy garments
- one-colour_blue / navy / white single-colour versions

- Navy         #0B1320   (RGB 11, 19, 32)
